# Тандыр Сетка — интернет-магазин

Простой интернет-магазин на чистом HTML/CSS/JS. Без фреймворков, без сборки —
открыл и работает. Все товары и настройки — в JSON-файлах, редактируются
без знания программирования.

## Структура проекта

```
tandyr-shop/
├── index.html              страница сайта (структура и разметка)
├── css/
│   └── style.css           все стили
├── js/
│   └── main.js              вся логика: каталог, корзина, заказ, поиск/фильтр,
│                             отправка в Telegram и Google Таблицу, SEO-разметка
├── data/
│   ├── products.json        ← ТОВАРЫ. Редактируете вы, без программиста
│   └── config.json           название магазина, телефон, ключи Telegram/Sheets
├── img/                      фотографии товаров (сейчас пусто — см. img/README.txt)
├── robots.txt                для поисковых роботов
├── sitemap.xml                карта сайта
├── google-sheets-webhook.gs   код для Google Apps Script (приём заказов в таблицу)
└── README.md                  этот файл
```

## Как запустить и проверить локально

Файл `index.html` подгружает `data/products.json` и `data/config.json` через
`fetch()`. Браузеры блокируют такие запросы, если просто открыть файл
двойным кликом (`file://…`). Поэтому для локальной проверки нужен
простой локальный сервер:

```bash
cd tandyr-shop
python3 -m http.server 8000
```

Затем откройте `http://localhost:8000` в браузере.

(Альтернатива — расширение "Live Server" в VS Code, если пользуетесь им.)

**На реальном хостинге этот шаг не нужен** — там сайт открывается по обычной
ссылке (`https://ваш-домен/...`), и `fetch()` работает как положено.

## Как добавить/изменить товар

Откройте `data/products.json` — это обычный список объектов:

```json
{
  "id": 15,
  "name": "Название товара",
  "description": "Описание товара",
  "images": ["img/moy-tovar-1.jpg", "img/moy-tovar-2.jpg"],
  "category": "Категория",
  "options": [
    { "diameter": "Вариант 1", "price": 500 },
    { "diameter": "Вариант 2", "price": 700 }
  ]
}
```

- `id` — уникальный номер, у каждого товара свой
- `category` — если категория новая, кнопка фильтра появится в каталоге
  автоматически, ничего в коде менять не нужно
- `options` → `diameter` — это подпись варианта (диаметр, размер, "со
  сковородкой" и т.п. — что угодно), `price` — цена за этот вариант
- `images` — **массив** путей к фото. Один элемент — просто фото без
  карусели. Два и больше — на карточке и в окне товара появляются стрелки,
  точки-индикаторы и свайп на телефоне, листающие фото по кругу. Второе и
  последующие фото подгружаются только когда на них реально переключились
  (ленивая загрузка) — при открытии страницы скачивается только первое
  фото каждого товара
- Если файла нет или он не загрузился — сайт сам покажет схематичную
  иконку по категории — ничего не сломается

⚠️ Товары с `id: 7` и `id: 8` (сетки 2х и 3х рівневі) дополнительно
прописаны как обычный текст прямо в `index.html` — это сделано специально,
чтобы поисковые роботы видели их сразу, без выполнения JavaScript. Если
меняете эти два товара — поправьте текст **в двух местах**: и в
`products.json`, и в блоках `id="static-card-7"` / `id="static-card-8"`
внутри `index.html`.

## Как добавить фото товаров

Просто положите файлы в папку `img/` с именами, которые указаны в поле
`image` каждого товара (например `img/2x.jpg`). Подробности — в
`img/README.txt`.

## Настройки магазина (data/config.json)

```json
{
  "shopName": "Тандыр Сетка",
  "currency": "грн",
  "phone": "+380730777092",
  "phoneDisplay": "073 077 70 92",
  "telegram": { "botToken": "...", "chatId": "..." },
  "sheets": { "webhookUrl": "", "secret": "..." }
}
```

- `phone` / `phoneDisplay` — телефон в шапке, футере и контактах
- `telegram` — при оформлении заказа сайт шлёт уведомление в этот чат
- `sheets` — при оформлении заказа сайт дописывает строку в Google Таблицу
  (см. `google-sheets-webhook.gs` для настройки)

## Подключение Google Таблицы

Инструкция целиком — в комментариях файла `google-sheets-webhook.gs`.
Коротко: создаёте таблицу → Apps Script → вставляете код → разворачиваете
как веб-приложение → полученную ссылку и секретный ключ вписываете в
`data/config.json` → `sheets.webhookUrl` и `sheets.secret`.

## Как разместить на GitHub Pages

1. Создайте новый репозиторий на github.com (можно назвать `tandyr-shop`)
2. Загрузите в него **содержимое** папки `tandyr-shop` (не саму папку, а
   всё, что внутри неё — `index.html` должен лежать в корне репозитория)
   — через веб-интерфейс (кнопка "Add file → Upload files") или `git push`
3. В репозитории: **Settings → Pages**
4. В разделе "Build and deployment" → Source: **Deploy from a branch**
5. Branch: **main** (или `master`), папка: **/ (root)** → Save
6. Через 1–2 минуты сайт будет доступен по адресу вида
   `https://ваш-логин.github.io/tandyr-shop/`
7. Проверьте сайт по этой ссылке — каталог, корзина, оформление заказа,
   Telegram-уведомление должны работать сразу, без дополнительных настроек

⚠️ **Про публичный репозиторий.** Если репозиторий на GitHub публичный —
файл `data/config.json` с токеном Telegram-бота виден всем, кто зайдёт в
репозиторий (не только на сайте, но и в самом коде на GitHub). Боты
постоянно сканируют публичные репозитории именно в поисках таких токенов.
Если это критично — сделайте репозиторий **приватным** (GitHub Pages
работает и с приватными репозиториями на платных тарифах; на бесплатном
приватный репозиторий Pages не публикует — тогда либо публичный репозиторий
с пониманием риска, либо позже переходим на вариант с прокси-сервером,
который мы уже обсуждали).

Как только зальёте — пришлите ссылку на сайт, я гляну и поправлю
`canonical`, `robots.txt` и `sitemap.xml` под настоящий адрес.



1. `index.html` → `<link rel="canonical" href="https://your-domain.example/">`
   — замените на настоящий адрес
2. `robots.txt` и `sitemap.xml` → замените `your-domain.example` на реальный домен
3. Загрузите фотографии в `img/` (см. выше)
4. Если хотите Google Таблицу — настройте `sheets.webhookUrl` в `config.json`
5. Токен Telegram-бота в `config.json` виден в исходном коде страницы — это
   нормально для уведомлений, но помните об этом (см. `PROMPT.md`, раздел
   "Безопасность")

## Оплата

Приём оплаты картой на сайте не подключён — форма заказа сейчас только
собирает данные и уведомляет вас. Чтобы принимать оплату сразу на сайте,
нужно отдельно подключать эквайринг (например plata by mono от monobank).
